# 요청 31 · 2026-09-26 재점검

사용자 원문은 USER_REQUESTS.md 요청 31에 실행 전에 기록했다. 요청 30 수정 후 다른 경계들을 점검한 작업이다.

## 수정과 회귀

| 경계 | 재현한 문제 | 수정 |
|---|---|---|
| 모든 매수의 연구 게이트 | adjusted=true만으로 빈/타종목/손상/오래된 가격 이력을 통과 | `PriceHistory.usableFor`를 필수 `buyBlockers`에 연결 |
| 분석 만료 | toMinutes 절삭으로 30분을 초과해도 승인 | Duration 전체 정밀도로 30분 초과 차단 |
| 수정주가 수치 | close/volume은 유한하지만 high가 곱셈 overflow로 Infinity | 원본과 변환 후 전체 OHLCV 검증 |
| 가격 추적 시각 | 잘못된 미래 시세를 캐시해 후속 정상 시세를 계속 낡았다고 버림 | 무효 시세는 순서 캐시에 넣지 않고 준비 상태와 캐시 무효화 |
| 운영시간 종료 | 15:15를 넘겨 반환한 REST가 화면/근거리 WS 구독에 반영 | 응답 후 운영시간 재검사·구독 종료·늦은 WS 무시 |

초기 6개 신규 JVM 테스트 중 5개가 수정 전 실패했다. 당일 미완성 봉 제외는 정상 동작 비교 테스트다. 이후 정기매수의 공통 게이트 우회 방지와 루프 실행 전 장 종료 WS 도착 테스트를 추가했다. 모두 합성 자료·모형 포트이며 실제 주문/시세 호출이 아니다.

## 가격 이력 계약

- 요청 종목과 일치, `asOf`가 미래가 아니어야 한다.
- 당일 미완성 봉은 제외하며 미래 날짜는 거절한다.
- 완료된 일봉이 최소 하나 필요하고 중복 날짜, 비유한 OHLCV, 역전 고저가, 범위 밖 종가, 음수 거래량을 거절한다.
- 마지막 완료 봉은 최대 7일 전까지다. 기존 기술지표 검사와 같은 보수적인 달력일 기준이다. 거래소 휴장일 공급자나 완전한 시계열 보증을 대체하지 않는다.
- 지표 계산에 필요한 61개/이평 기간 길이는 기존 전략별 검사가 별도로 요구한다.
- 이 무결성 검사로 원시 NH 일봉을 수정주가로 승인하지 않는다. 데이터 사용권한/수정주가 공식 계약 게이트는 유지한다.
