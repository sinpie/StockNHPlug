# UI와 사용성

## 화면 체계

밝은 회백색 바탕, 흰 카드, 진한 청록색 주요 동작, 짙은 남색 자산 카드를 사용합니다. 색상만으로 의미를 전달하지 않고 모의/정지/접수/미확인 문구를 함께 표시합니다. 한국 주식 관례에 맞춰 손익 양수는 적색, 음수는 청색을 사용합니다.

| 화면 | 내용 | 주요 동작 |
|---|---|---|
| 잠금 | 기기 인증, 보안 설명 | PIN/패턴/기기 비밀번호 확인 |
| 홈 | 순자산, 평가손익, 예수금, 자동매매 상태, 데이터 준비 점검, 종목 점수 | 계좌 연결, 동기화, 세션 시작/정지 |
| 전략 | 종목 목록, 최소 점수, 예산, 보유수, 세션 손실 한도, 자동매도 동의 | 유효성 확인 후 저장 |
| 리서치 | 가격·재무·공시 출처, 보고서 기간, 지표, 매수 차단 근거 | 관심종목 분석 |
| 보유 | 수량, 평균단가, 잔고 현재가, 평가손익, 실시간 체결가 | 새로고침 |
| 기록 | 앱 주문 저널 / 계좌 전체 체결 / 30일 일별 손익 / 일별 보유 이력 | 탭 전환, 손익 조회 |
| 로그 | 시간·레벨·메시지, 오류 필터 | 실시간 확인 |
| 설정 | 암호화 키 입력, 계좌 선택, 개인정보 안내 | 키 저장, 모의 연결, 전체 로컬 삭제 |

## 상호작용

- 실제 데이터가 없으면 빈 상태나 `—`를 표시합니다. 가상 수익이나 예시 보유종목은 실제처럼 표시하지 않습니다.
- 키는 다시 표시하지 않습니다. 재입력 저장 시 연결·토큰이 초기화됩니다.
- 실행 중에는 키·전략·계좌 전환을 막습니다. 정지 버튼은 하단과 시스템 알림에서 접근할 수 있습니다.
- 시작 전 모의 환경, 자동매도 범위, OS/네트워크 한계와 신규매수 차단을 설명합니다.
- 외부 기사/공시 HTML을 WebView로 렌더링하지 않으므로 콘텐츠가 앱 내부에서 코드를 실행하지 않습니다.
- 스크롤 가능한 레이아웃과 최소 48dp 주요 버튼, 시스템 글꼴 확대를 지원하는 sp 텍스트를 사용합니다. 화면 폭과 200% 글꼴 실기기 검증은 출시 체크리스트에 있습니다.
- 작업 중 진행 막대와 실패 상태를 표시합니다. 알림 권한이 없으면 백그라운드 자동매매를 시작하지 않습니다.

## 제한

현 버전은 스마트폰 단일 열 UI입니다. 태블릿 다중 패널·사용자 지정 드래그 차트·CSV 내보내기·다크모드·전략 편집 DSL은 포함하지 않습니다. 매매 설정은 앱의 검증된 필드로만 입력해 임의 코드를 실행하지 않습니다. 전체 계좌 체결과 앱 주문을 구별하며 계좌 손익을 앱 전략 수익으로 단정하지 않습니다.

## 확인한 화면

API 30 / 1080×1920 테스트 호스트에서 홈 화면을 렌더링하고 6개 탭 이동·비연결 상태의 실행 차단을 확인했습니다. [대시보드 캡처](images/dashboard.png)는 사용자 데이터가 없는 UI 전용 호스트의 결과이며 production 화면 보호를 해제한 것이 아닙니다.

## 증권사별 기록 구분

앱 주문 카드에는 증권사 ID와 마스킹한 계좌번호를 함께 표시합니다. 보유 이력은 선택된 증권사/계좌/환경으로 필터링합니다. 현재 앱에 연결되는 구현은 NHPlug 모의 API 한 종류이며 다중 API/전략 선택 UI는 아직 없습니다.
