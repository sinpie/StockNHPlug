# UI와 사용성

## 화면 체계

밝은 회백색 바탕, 흰 카드, 코발트색 주요 동작, 짙은 남색 자산 카드를 사용합니다. 색상만으로 의미를 전달하지 않고 모의/정지/접수/미확인 문구를 함께 표시합니다. 한국 주식 관례에 맞춰 손익 양수는 적색, 음수는 청색을 사용합니다.

| 화면 | 내용 | 주요 동작 |
|---|---|---|
| 잠금 | 기기 인증, 보안 설명 | PIN/패턴/기기 비밀번호 확인 |
| 홈 | 총자산, 평가손익, 예수금, 자동운용 상태, 운용 준비, 분석 요약 | 계좌 연결, 동기화, 세션 시작/정지 |
| 전략 | 전략·그룹 목록, 추천 지표, 정기매수, 그룹 예산과 계좌 공통 한도 | 그룹 추가·편집, 유효성 확인 후 저장 |
| 시세 | 현재가·그룹별 타겟 / 분석 | 종목·그룹 검색, 종목별 수동 조회, 분석 |
| 자산 | 보유종목 / 계좌 손익 / 보유 이력 | 잔고·손익 조회 |
| 내역 | 앱 주문 / 증권사 체결 / 실행 로그 | 선택 계좌·전체 주문 전환, 오류 필터 |
| 설정 | 암호화 키 입력, 계좌 선택, 개인정보 안내 | 키 저장, 모의 연결, 전체 로컬 삭제 |

## 상호작용

- 실제 데이터가 없으면 빈 상태나 `—`를 표시합니다. 가상 수익이나 예시 보유종목은 실제처럼 표시하지 않습니다.
- 키는 다시 표시하지 않습니다. 재입력 저장 시 연결·토큰이 초기화됩니다.
- 실행 중에는 키·전략·계좌 전환을 막습니다. 정지 버튼은 하단과 시스템 알림에서 접근할 수 있습니다.
- 시작 전 모의 환경, 자동매도 범위, OS/네트워크 한계와 신규매수 차단을 설명합니다.
- 외부 기사/공시 HTML을 WebView로 렌더링하지 않으므로 콘텐츠가 앱 내부에서 코드를 실행하지 않습니다.
- 스크롤 가능한 레이아웃과 최소 48dp 주요 버튼, 시스템 글꼴 확대를 지원하는 sp 텍스트를 사용합니다. 화면 폭과 200% 글꼴 실기기 검증은 출시 체크리스트에 있습니다.
- 작업 중 진행 막대와 실패 상태를 표시합니다. 알림 권한이 없으면 백그라운드 자동매매를 시작하지 않습니다.

## 제한

현 버전은 스마트폰 단일 열 UI입니다. 태블릿 다중 패널·사용자 지정 드래그 차트·CSV 내보내기·다크모드·전략 편집 DSL은 포함하지 않습니다. 매매 설정은 앱의 검증된 필드로만 입력해 임의 코드를 실행하지 않습니다. 전체 계좌 체결과 앱 주문을 구별하며 계좌 손익을 앱 전략 수익으로 단정하지 않습니다.

## 확인한 화면

API 30 / 1080×1920 테스트 호스트에서 5개 작업 공간과 하위 탭 이동·비연결 상태의 실행 차단을 확인했습니다. [대시보드 캡처](images/dashboard.png)는 사용자 데이터가 없는 UI 전용 호스트의 결과이며 production 화면 보호를 해제한 것이 아닙니다.

## 증권사별 기록 구분

앱 주문 카드에는 증권사 ID와 마스킹한 계좌번호를 함께 표시합니다. 보유 이력은 선택된 증권사/계좌/환경으로 필터링합니다. 현재 앱에 연결되는 구현은 NHPlug 모의 API 한 종류이며 다중 API 선택 UI는 아직 없습니다. 전략은 등록된 알고리즘을 선택해 여러 개 만들 수 있습니다.

## 전략·그룹 UI

[전략 목록 캡처](images/strategy-groups.png)는 API 30 테스트 호스트에서 구성만 넣어 확인한 화면입니다. 실제 계좌·보유 데이터는 포함하지 않으며 production 화면 보호는 유지합니다. 두 기본 전략 카드의 텍스트·토글·관리 버튼 배치를 육안 확인했고 편집·저장 흐름은 Android UI 테스트로 확인했습니다.

전략 탭은 기본 물타기/리밸런싱 카드, 그룹 수, 추천/정기매수 상태와 관리 버튼을 표시합니다. 전략 관리의 그룹/추천매수/정기매수 탭에서 역할을 분리합니다. 그룹은 전체 화면 편집으로 종목·목표 비중·자본/주문/일 한도·전략 조건·일정 상속을 설정합니다. 같은 종목을 여러 그룹에 등록할 수 있으며 확정 체결이 없으면 보유량을 만들지 않습니다. 5개 지표 조합 선택 후 각 토글/조건값을 수정하고 명시적으로 저장합니다. 숫자 오류를 이전 유효값으로 몰래 대체하지 않습니다. 계좌 공통 한도는 별도 펼침 영역에서 설정하며 자동매도는 그룹 소유량에만 적용합니다.

## 백그라운드 실행
시작 후 다른 앱 사용 및 최근 앱 목록 제거는 세션 정지 동작이 아닙니다. 앱의 정지 버튼 또는 지속 알림의 즉시 정지를 사용합니다. 앱 자체의 6시간 만료는 제거했습니다. 강제 종료·재부팅·절전·통신 장애 시 무중단 실행은 보장하지 않습니다. 현재 NH 그룹 대사 미검증에 따른 시작 잠금은 유지합니다.

## 현금 파킹

2026-09-20 [전략 목록 캡처](images/strategy-groups.png)를 파킹 카드가 포함된 테스트 호스트 화면으로 갱신했습니다. 계좌 데이터 없는 설정 fixture이며 카드의 상태·금액·설정 버튼 배치를 육안 확인했습니다. 입력 오류 차단/저장 흐름은 Android 테스트로 확인했습니다.
전략 목록 상단의 현금 파킹 카드에서 상태·최소 현금·최대 금액·확정 보유/실현손익을 확인하고 `파킹 설정`으로 편집합니다. 별도 화면에서 종목과 금액/회전/시간 한도를 저장합니다. 기본 꺼짐이며 예시 종목을 실제 설정에 넣지 않습니다. 잘못된 값은 저장할 수 없습니다. 파킹 기록은 `현금 관리 / 파킹`으로 표시합니다. [운영 조건](PARKING.md).

## 가격 추적 표시
시세·분석 → 시세·타겟의 종목 카드에서 그룹·종목·방향·전략 제시가·저점/고점·실제 트리거·거리·전송 상태를 구분합니다. 타겟이 없으면 빈 상태를 표시하며 임의 시세를 만들지 않습니다. 상세 정책은 [PRICE_TRACKING.md](PRICE_TRACKING.md).

## 2026-09-20 사용성 재구성 (요청 24 이전 이력)
하단을 홈·자동매매·시세/분석·자산·활동의 5개 작업 공간으로 줄였습니다. 가격 추적은 시세와 함께, 손익/보유 이력은 자산과 함께, 주문/체결/로그는 활동에 모았습니다. 연결·보안은 상단 설정, 전략·그룹/파킹/계좌 공통 한도는 자동매매 안에서 관리합니다.

`WorkspaceNavigation`은 큰 분류만, 각 Workspace는 하위 탭만 소유합니다. `PriceTrackingScreen`은 종목코드·이름·그룹 검색, 공유 시세와 그룹별 제시가/극값/트리거를 표시합니다. 첫 20개를 표시하고 더 보기로 추가합니다. 1초 화면 시계로 시세가 15초를 넘으면 지연/재확인 상태로 바꾸며 과거 ready 상태를 주문 가능처럼 표시하지 않습니다. 네트워크 조회를 1초마다 시작하는 기능은 아닙니다.

자동매매 정지 중에도 연결된 설정/보유 종목을 명시적으로 한 종목씩 조회할 수 있습니다. 장외에는 거래시간을 안내하고 API를 호출하지 않습니다. 자동주문/타겟은 만들지 않으며 백그라운드 자동 조회도 시작하지 않습니다. 비연결·실행 중·작업 중에는 수동 조회를 막습니다.

`StatusBanner`는 마지막 처리 결과를 스크롤 위에 고정하고 긴 메시지는 펼쳐 봅니다. 활동의 앱 주문은 선택 계좌를 기본으로 필터링하며 전체 계좌 버튼을 제공합니다. 체결/손익의 계좌 전체 의미는 유지합니다. 새 화면 검증 결과는 VERIFICATION.md에 기록합니다.

새 선택 메뉴와 배너는 기존 청록/회백색으로 통일하고 종목명이 없을 때 코드가 두 번 보이지 않도록 했습니다. [시세 화면](images/market-workspace.png), [130% 글꼴 시세 화면](images/market-workspace-130.png), [130% 글꼴 홈](images/dashboard-130.png)을 확인했습니다. 시세 캡처는 상단에 합성 테스트임을 표시하며 실제 시장 데이터가 아닙니다. 100%·130%에서 화면 이동/검색/그룹 스크롤/계좌별 기록 필터를 확인했습니다. 모든 기기와 200% 확대를 검증한 것은 아닙니다.
# 2026-09-20 시세 추적 설정과 이력

연결 및 보안 설정에 `시세 추적 · 배터리` 영역을 묶고 `WebSocket 시세 추적` 스위치를 제공한다. 기본 ON, OFF는 REST 2~10초 조회 예약이다. 자동매매 중에는 변경할 수 없고 정지 후 저장·계좌 재연결로 적용한다. 네트워크·종목 수·서버 제한에 따른 지연 가능성을 같은 영역에서 안내한다.

시세 화면은 종목 아래 각 전략그룹의 매매 타겟을 별도 표시한다. 전략 제시가, 추적 최저/최고, 매수 저점 또는 매도 고점, 실제 트리거와 상태를 표시한다. 다음 날에도 미완료 이력을 유지한다. 비활성 보관 이력은 저장되지만 현재 화면의 활성 타겟 목록에는 표시하지 않는다.
# 2026-09-20 금융 화면 개편

요청 24: 하단 메뉴는 **홈 · 전략 · 시세 · 자산 · 내역**. 시세는 **현재가/분석**, 자산은 **잔고/손익/이력**, 내역은 **주문/체결/로그**, 설정은 **계좌/시세/보안**으로 구분한다. 이전 화면명의 긴 조합을 현재 명칭으로 대체한다.

네이비 자산 카드, 코발트 주요 동작, 얇은 경계선과 흰 카드, 일관된 간격·숫자 강조를 적용했다. 설정은 전체 화면으로 펼쳐 좁은 대화상자에서 키를 입력하지 않게 했다. 손익은 국내 표기 관례의 상승 빨강/하락 파랑과 부호를 함께 표시한다.

전문 조회 기능: 최우선 호가·스프레드, 보유주식 내 비중·수익률·정렬, 실제 일별 종가 차트, 주문 상태/종목 필터, 미체결 포함 체결 필터. 새로운 비공식 시세 제공자나 주문 기능을 추가하지 않는다. 원시 일봉의 수정 기준 미검증 표시와 기존 자동주문 잠금을 유지한다.

요청 중 작업명/분석 진행률과 취소를 표시한다. 자동운용 중 수동 조회는 비활성화한다. 취소 시 연결을 종료하고 재연결을 안내한다. 그룹/파킹 저장 실패는 초안을 유지한다. [비동기 및 기능 블록 검토](ASYNC_REVIEW.md).

하단 메뉴 간 이동 시 `SaveableStateHolder`로 각 페이지의 스크롤·선택 탭·검색을 복원한다. 키 입력은 이 저장 범위에 포함하지 않는다.
