## 처리하는 정보와 목적

앱은 사용자가 직접 입력한 NHPlug 앱키/secret, 선택적 OpenDART 인증키, 접근토큰, 계좌번호, 잔고, 시세, 주문 및 체결, 손익, 전략 설정, 운영 로그를 사용합니다. 목적은 본인 계좌 조회, 사용자가 설정한 모의 자동매매, 결과 확인, 오류 점검입니다. 앱 자체 회원가입은 없습니다.

## 저장과 전송

키·토큰·전략 설정·앱 주문 저널·보유 스냅샷·로그는 휴대폰 앱 전용 저장소에 Android Keystore 기반으로 암호화하여 저장합니다. 실시간 시세·재무·공시·체결 및 손익 조회 결과는 메모리에서 표시합니다. 개발자 운영 서버로 보내거나 광고·행태 분석을 위해 수집하지 않습니다.

인증 및 사용자가 요청한 기능을 위해 NHPlug 공식 서버로 앱키·secret·토큰·계좌번호·주문정보가, OpenDART 공식 서버로 해당 인증키·기업고유번호·조회조건이 전송됩니다. 네트워크 제공자는 연결 메타데이터를 처리할 수 있습니다. 전송은 HTTPS/WSS를 사용합니다. 사용자는 각 제공자의 약관·개인정보 처리방침을 확인하고 본인 사용 권한이 있는 키를 입력해야 합니다.

## 보관과 삭제

암호화 주문 저널과 설정은 사용자가 삭제할 때까지 보관하고, 로그는 최근 500개를 유지합니다. 보유 스냅샷은 계좌·일자별 마지막 조회만 저장하며 전체 최근 365개를 유지합니다. 앱의 ‘키 및 기기 내 전체 기록 삭제’ 또는 Android 앱 데이터 삭제/앱 제거로 로컬 데이터를 삭제할 수 있습니다. 클라우드 백업과 기기 이전 대상에서 제외합니다.

기기 데이터 삭제는 증권사 계좌·주문·체결·법정 보관정보를 삭제하거나 주문을 취소하지 않습니다. 토큰/키 폐기와 계좌 관련 요청은 NH투자증권 또는 해당 제공자에 별도 요청해야 합니다.

## 권한

인터넷: 공식 API 조회/주문. 알림과 foreground service: 사용자가 시작한 자동매매 세션의 상태와 정지 제공. 오버레이 숨김: 다른 앱이 거래 화면을 가려 오작동시키는 것을 방어. 연락처·위치·SMS·공용 저장소 접근을 요청하지 않습니다.
