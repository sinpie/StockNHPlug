# 데이터 출처 및 이용조건 등록부

검토일: **2026-09-19**. 아래 내용은 공개 문서 확인과 구현 결정입니다. 앱 배포·재배포·유료 제공에 대한 포괄적 법률 허가를 의미하지 않습니다. 출처가 추가되거나 약관이 바뀌면 이 파일, `SourceRegistry`, 개인정보 문서와 테스트를 함께 수정합니다.

## 수집 원칙

1. 공식 API 또는 계약된 피드만 사용합니다. 공개 웹페이지, robots.txt 허용, 무료 검색 가능 여부만으로 크롤링·가공·재배포 권한을 추정하지 않습니다.
2. 데이터의 조회권한, 자동매매 분석권한, 저장권한, 앱 내 표시권한, 재배포권한을 별개로 확인합니다.
3. 키는 사용자가 기기 내에서 직접 입력합니다. 개발자 공용 API 키를 APK에 심거나 개인 키를 타인에게 공유하지 않습니다.
4. 출처·자료 기준일·수신시각·수정 여부·보고서 종류를 보존합니다. 누락·휴장·오류를 정상 0건으로 바꾸지 않습니다.
5. 출처 추가 전 표의 상태와 근거 링크, 허용 범위, 보관/삭제, 호출량, 승인 담당/계약 식별자를 채웁니다. 미확정이면 연결하지 않습니다.

## OpenDART 운영

공식 약관은 신청용도·환경 등록, 호출 제한, 서비스 변경, 키의 제3자 사용 금지와 저작권 관련 의무를 포함합니다. 원천 공개 정보라도 제3자 권리와 개인정보를 별도로 확인합니다. 현재 구현은 공시 제목·접수번호·재무계정으로 범위를 제한하고 보고서 본문과 임원 개인정보를 수집하지 않습니다. 상태 013은 자료 없음으로, 기타 인증/한도 오류는 실패로 처리합니다. 기기 외부 서버에 중계하지 않습니다.

## 호출 및 보관

- NHPlug 요청 간격 최소 250ms, 한 연결 10종목 + 체결 통보. 429 자동 재시도/키 재발급 없음.
- OpenDART 요청 간 최소 300ms, 사용자 분석 요청에만 호출. 무제한 상장사 전체 수집 없음.
- 뉴스 수집 없음. 검색 API를 비공식 크롤링으로 대체하지 않음.
- 앱 로그 최근 500개, 주문 저널은 사용자가 삭제할 때까지 기기 암호화 보관. 원천 API 응답 전체를 로그나 저장소에 넣지 않음.
- 손익 조회·재무·공시 데이터는 현재 메모리 전용. 앱 주문과 계좌별 보유 스냅샷(하루 마지막 조회, 전체 최근 365개)을 암호화 영속 보관합니다. 별도 시세 데이터베이스/서버 재배포는 구현하지 않았습니다.

## 재검토 절차

출시 전 및 제공자 약관 변경을 인지할 때 원문을 다시 확인합니다. 계약된 데이터가 추가되면 `docs/CHANGELOG.md`에 날짜·근거·변경 목적을 기재하고 접근 호스트와 수집 필드를 코드 검토합니다. 승인 만료·이용중단 요청 시 해당 공급자를 비활성화하고 종목 신규매수도 차단합니다. 이 문서는 저장소에서 지속 관리하며 자동 약관 감시 서비스는 만들지 않았습니다.

## 현재 신규매수 차단의 이유

요구사항은 수정주가·재무·공시·뉴스를 **모두** 확인하는 것입니다. 제공자 이용조건이 불명확한 상태에서 요구사항을 생략하거나 무단 수집하는 대신, 신호 점수는 참고용으로 보여주고 신규 주문은 차단합니다. 기존 계약 정보가 제공되면 해당 범위의 어댑터를 완성할 수 있습니다.

## 2026-09-19 제공자 계층 분리

NHPlug 가격이력은 marketdata/NhPriceHistoryProvider로 이동하고 주문 Broker에서 분리했습니다. OpenDART는 research/provider/DartClient로 이동해 CorporateResearchProvider를 구현합니다. 가격·재무·뉴스는 AppContainer에서 독립적으로 주입합니다. 이용 출처·인증 호스트·허용 범위는 바뀌지 않았으며 새 사이트/API를 추가하지 않았습니다. 뉴스 계약/수정주가 미검증 차단도 유지합니다.

## 그룹 체결 대사 게이트 (2026-09-19)

기존에 확보한 NHPlug 공식 OpenAPI의 cashBuy/cashSell 응답은 mkt_orr_no, dailyOrderExecution 응답은 itg_orr_no입니다. d2 실시간 예제의 orderno 역시 두 ID 사이의 영속 대응과 재접속 누락 복구를 입증하지 않습니다. 숫자 길이·종목·수량·시간으로 관계를 추정하지 않습니다. 공식 대응/대사 명세와 모의계좌 증거 확보 전 GroupExecutionSource를 주입하지 않으며 그룹 자동주문을 차단합니다. 이번 변경에 새 데이터 사이트 수집이나 출처 권한 승격은 없습니다.

## 파킹 데이터
파킹 기능은 기존 공식 제공자만 사용하며 새 수집처/크롤러를 추가하지 않습니다. 파킹 매수도 동일한 연구 근거를 요구하므로 기업 재무 등의 근거가 없는 ETF 상품을 자동 허용하지 않습니다. 사용자 지정 종목이 곧 API 지원/상품 적격성 승인을 뜻하지 않습니다. 상품별 공식 자료·거래 지원 검증은 출시 전 필요합니다.

## 2026-09-20 현재가 경로 검토
[NHPlug 공식 API](https://www.nhplug.com/apiservice)의 currentPrice는 live 전용이므로 해당 읽기 경로만 운영 8443을 사용합니다. 시세 oc도 운영 7070이며 계좌/주문은 모의입니다. 새 크롤러나 비공식 공급자를 추가하지 않았습니다. 당일 상하한과 양방향 호가를 필수로 검증합니다. 시세는 메모리 전용, 재배포하지 않습니다. NamuMagic은 사용자 소유 알고리즘 참조이며 시장 데이터 공급원/이용권한의 근거가 아닙니다. 원본 커밋과 공식 KRX 자료는 [PRICE_TRACKING.md](PRICE_TRACKING.md)에 기록했습니다.

2026-09-20: 기존 NH currentPrice 제공자의 검증을 강화해 당일 제한 밖 bid/ask를 거절합니다. 수동 시세 조회도 동일 공식 API만 쓰며 신규 공급자·크롤러·원격 저장을 추가하지 않았습니다.
