# 변경 이력

## 2026-09-19 · 전체 재검증과 유지보수 주석

- Kotlin 소스와 테스트를 일관된 형식으로 정리하고 주요 클래스/함수에 책임·호출 순서·실패 처리 KDoc을 추가했습니다.
- CODE_FLOW.md에 launcher/서비스 진입점, 계좌 연결, 연구, 주문/종료 흐름도, 스레드 책임, 수정 위치별 검증 안내를 추가했습니다.
- 주문 결과 기록 실패 시 디스크 처리보다 먼저 정지하도록 수정하고 실행 중 손실 기준 재설정을 금지했습니다.
- 시세/잔고의 초 미만 만료 경계, 잘못된 종목·비정규장 청산 평가를 보강했습니다.
- 계좌 전환 시 재구독, 초기 동기화 후 연결 표시, 키 교체 시 이전 조회 제거, 구독 상한 초과 시 명시적 실패를 적용했습니다.
- 자동매매 중 수동 작업 경쟁을 제한하고 서비스 상태 관찰자 중복 및 foreground 전환 예외를 처리했습니다.
- 복호화된 저장 JSON의 필수 배열 손상을 빈 이력으로 취급하지 않도록 변경했습니다.
- JVM 회귀 테스트 5개와 별도 테스트 디렉터리를 사용하는 LocalStore 기기 테스트 3개를 추가했습니다.
- GitHub Actions가 폐지된 Android SDK `tools` 패키지를 요구하던 구성을 수정했습니다. 실제 실행 결과는 VERIFICATION.md에 기록합니다.

## 2026-09-19 · 0.1.0 초기 구현

- Kotlin/Compose Android 프로젝트와 Gradle wrapper 구성, API 36 대상.
- 사용자 요청에 따라 응용 → 매매 → 실제 REST/WS 계층 분리.
- 연구 데이터 계층 추가: 일봉, 수정계수 변환, OpenDART 재무/공시, 라이선스 기반 뉴스 포트.
- 공식 API·약관 검토 후 NAVER 검색 뉴스 자동매매 분석 연결 제외. 미검증 수정주가/뉴스는 신규매수 차단으로 반영.
- 한국어 6개 화면, 키/계좌 설정, 지표 근거, 오류 필터, 앱 주문과 계좌 체결/손익 구분.
- Keystore 암호화, 화면/오버레이 방어, 백업 차단, 기기 잠금, 사용자 시작 foreground 세션.
- 주문 사전 저널, 실패 후 재주문 방지, 신선도·한도·환경 검사, 현금 지정가 IOC.
- 계층별 클래스, 데이터 이용방침, 보안, 전략, UI, 개인정보 초안, 출시 게이트 문서 작성.
- JVM 테스트 및 Android Keystore 테스트 코드 추가. 실행 결과는 `VERIFICATION.md`를 정본으로 사용.
- 계좌/환경/일자별 보유 스냅샷(최근 365개) 암호화 보관 추가. 계좌 변경 시 손익 초기화, 설정 변경 후 실시간 재연결 요구, 종료 중 데이터 삭제 경쟁 조건 방어.

이후 변경 시 날짜·변경 이유·영향·검증 결과를 기록합니다. 출처 조건은 `DATA_SOURCES.md`, 구현 책임은 `ARCHITECTURE.md`에도 함께 반영합니다.
