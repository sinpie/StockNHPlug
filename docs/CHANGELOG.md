## 2026-09-26 · 요청 30 전체 디버깅

- 공유 시세 연결 직렬화 대기 중 계좌를 정지해도 뒤늦게 구독이 등록되던 오류 수정. lease별 취소 세대로 대기 요청을 무효화하며 이후 명시적 연결은 허용.
- 취소를 무시하는 주문 가능수량 어댑터가 늦게 반환했을 때 사전 저널/주문 전송을 계속하던 오류 수정. 진입·조회 완료·예약 후 전송 직전에 코루틴 취소를 검사. 미전송 예약은 REJECTED, 이미 전송한 불명확 결과는 기존 UNKNOWN 정책 유지.
- 새 분석 설정 저장 후 조회 실패 시 이전 근거가 남던 오류 수정. 새 분석 시작 시 이전 근거/후보를 폐기하고 완결 배치만 게시.
- 통계 내보내기 중 중복 결과/취소/화면 열기 실패 콜백이 busy를 풀던 오류 수정. 실제 쓰기와 close가 끝날 때까지 상태 소유권 유지.
- 신규 JVM 회귀 4개는 수정 전 모두 실패를 재현했다. 수정 후 JVM 1,148개와 Android 35개 통과(opt-in 1개 제외), 린트/Debug APK/Release AAB 및 감사 성공. 실제 API·주문 재검증은 수행하지 않았다. 상세 결과는 VERIFICATION.md.
