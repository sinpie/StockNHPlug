# 개인 손익 다운로드와 운용 점검

요청 26 (2026-09-20). 원문은 [USER_REQUESTS.md](USER_REQUESTS.md). 이 기능은 실매매 출시 승인이 아니다.

## 형식 선택

| 형식 | 용도 | 결정 |
|---|---|---|
| UTF-8 BOM CSV | Excel·LibreOffice·분석 도구에서 정렬/계산 | 기본 제공. 선택한 일/월/연 단위 통계 한 표 |
| ZIP 안의 CSV·설명서 | 여러 표를 한 파일에 보관 | 제공. 동일 계좌/연도 필터로 일·월·연 통계, 현금, 거래 동시 내보내기 |
| XLSX | 서식·차트·시트 | 이번 구현 제외. CSV로 계산 가능하며 추가 문서 엔진/종속성을 도입하지 않음 |
| PDF | 인쇄 | 이번 구현 제외. 재계산/분석이 어렵고 작은 화면 통계의 사용 목적과 우선순위가 다름 |

자산 → 통계 → 연도 및 기간 선택 → **통계 CSV** 또는 **전체 ZIP** → Android 시스템 저장 화면에서 위치 선택. ZIP의 ‘전체’는 선택 계좌와 연도 필터 안의 모든 표를 뜻한다. 다른 계좌와 섞이지 않는다. 파일 생성 시점의 전체 행을 쓰며 화면의 ‘더 보기’ 개수와 관계없다. 앱 운용 중에도 저장된 불변 스냅샷을 내보낼 수 있다. 다운로드가 증권사 조회/매매를 호출하지 않는다.

CSV는 BOM, CRLF, 모든 필드 큰따옴표, 필드 내부 큰따옴표 중복으로 기록한다. 한국어 헤더, KRW 단위, 생성 UTC 시각과 관측일 수를 제공한다. 금액/수량은 로캘 구분자 없이 숫자로 기록하고 음수 손익을 문자열 수식으로 변환하지 않는다. 종목코드는 작은따옴표로 앞자리 0을 보호한다. 수식 시작 문자(=,+,-,@ 및 전각 변형), 선행 공백/제어문자가 있는 텍스트에도 작은따옴표를 붙인다. 원본 이름을 수식으로 평가하지 않는다. 표 계산기의 다시 저장/가공 과정에서 보호 문자가 제거될 수 있으므로 외부 파일 변환을 앱이 보증하지 않는다.

ZIP 항목:

- `day.csv`, `month.csv`, `year.csv`: 같은 필터의 보고 손익, 별도 수수료/세금, 관측일, 이익/손실/보합일, 체결 주문 수, 평균가 기준 거래대금, 마지막 현금/자산.
- `balances.csv`: 날짜별 마지막 현금·총자산·평가손익·보고손익 및 잔고/손익/거래 관측 시각.
- `trades.csv`: 날짜별 마지막 증권사 누적 체결 응답. 종목·방향·주문/체결/잔여 수량·평균 체결가. 주문번호는 제외.
- `README.txt`: 마스킹 계좌, 범위, 생성 시각, 금액 의미와 누락·보안 주의.

미조회는 빈칸이며 0이 아니다. 날짜별 마지막 누적 체결을 반복해서 더하지 않는다. 접수는 체결이 아니다. 현금은 종가/정산 완료 현금이 아니며 입출금이 포함될 수 있다. 손익에서 수수료·세금을 다시 차감하지 않는다. 입출금 조정 수익률, 세무 신고 증빙, 원본 데이터 백업/복원 형식으로 사용할 수 없다. 장기 미수집 이력은 생성하지 않는다.

## 클래스와 비동기 흐름

1. `HistoryScreen`: 선택 계좌의 `AppState.history`와 연도/기간을 결정한다. `HistoryExport.capture`로 중첩 목록까지 복사한 요청을 만든다. 표시되지 않은 행도 포함한다.
2. `StockApp` / `AssetsWorkspace`: UI 이벤트를 Activity의 콜백에 전달한다. 저장소나 API 어댑터에 직접 접근하지 않는다.
3. `MainActivity.exportHistory`: 잠금 해제와 중복 요청 방지 후 CSV/ZIP의 `CreateHistoryDocument` launcher를 실행한다. 이 platform 계약은 AndroidX CreateDocument를 확장해 `CATEGORY_OPENABLE`을 명시하며 스트림으로 열 수 있는 파일을 요청한다. launcher는 잠금 화면 밖에서 항상 같은 순서로 등록한다.
4. `HistoryExportModel.prepare`: 요청을 메모리에만 보유하고 busy를 먼저 게시한다. ViewModel은 회전/기기 재인증 동안 유지된다. SavedState/Bundle/임시 평문 파일로 계좌 이력을 보관하지 않는다.
5. 시스템 결과 → `HistoryExportModel.save`: 선택된 단일 `content:` URI를 IO dispatcher에서 열고 `HistoryExport.write`를 호출한다. 각 CSV 행과 ZIP 항목에서 코루틴 취소를 확인한다. 출력 스트림 close까지 성공한 후에만 성공 메시지를 게시한다.
6. `HistoryExport`: Android와 독립된 직렬화 클래스. 기존 `HistoryAnalytics`를 재사용하여 화면과 동일하게 집계한다. ZIP 이름은 고정되어 경로 주입이 없다. 전체 계좌번호/주문번호/키/토큰/뉴스/시세 원본은 직렬화하지 않는다.

취소는 파일 저장 성공이 아니다. 프로세스 사망으로 메모리 요청이 사라진 경우 현재 계좌 자료를 대신 쓰지 않고 만료를 알린다. 외부 저장소의 용량/권한/네트워크/close 오류는 일반화된 오류로 표시한다. 문서 제공자 예외/URI는 로그에 남기지 않는다. 외부 문서 쓰기는 원자적이라고 보장할 수 없으므로 실패·사망 시 빈 파일/불완전 파일이 남을 수 있고 사용자가 저장소에서 삭제한다. 사용자의 기존 파일을 추정해서 자동 삭제하지 않는다. 다른 앱/클라우드 문서 제공자가 멈추면 OS I/O까지 강제 중단/시간 보장은 불가능하다.

## 추가 자동매매 기능 검토와 구현

자동운용에는 주문 전략 외에 ‘왜 멈췄는지’, ‘오늘 한도를 얼마나 예약했는지’, ‘어느 자료가 누락되었는지’를 확인할 수 있어야 한다. 기존 정지·원장·연구/시세 게이트에 다음 운용 점검을 추가했다.

- `OperationReview.inspect`: 읽기 전용 순수 계산. 선택 계좌의 증권사·환경·번호를 모두 비교하여 원장을 필터링한다. 저장 오류, 연결, 미확인 주문, 그룹 체결 대사는 차단으로 표시한다.
- 60초 이내 잔고/미래 시각, 종목별 연구 근거, 당일 현금·거래·손익 수집 여부는 별도 확인 항목이다. 미조회·휴장일을 거래 오류로 단정하지 않는다.
- 당일 매수 예약 금액은 거절 외 모든 매수 원장의 지정가×수량이다. 미체결/UNKNOWN/파킹도 포함하고 거절·다른 계좌·다른 날짜는 제외한다. BigDecimal로 합산하고 잔여 한도를 0 아래로 표시하지 않는다. 이는 체결대금이나 증권사 주문 가능 현금이 아니다.
- `OperationPanel`: 홈에서 차단/확인 수, 당일 예약·잔여 한도, 각 항목의 조치 방법을 펼쳐 본다. 정지가 증권사의 접수 주문을 취소하지 않는다는 점을 함께 표시한다. 1초 UI 시간 갱신은 API 조회를 발생시키지 않는다.
- `MultiAccountController.startSession`: UI에서만 막던 공유 자격증명 저장소 오류를 서비스 진입점에서도 차단한다. 다른 계좌가 정상이어도 공유 저장 오류 상태에서 새 계좌를 시작하지 않는다.

점검은 주문 허가를 대체하지 않는다. 매매 직전 TradingEngine/연구 게이트/그룹 대사에서 재검증한다. 연구 종목 목록은 등록된 그룹 기준이므로 전략 비활성 여부와 별개로 참고용이며 개별 매도까지 일괄 차단하는 새로운 정책은 아니다.

추가 검토했으나 근거 부족으로 자동화하지 않은 사항: 미확인 주문 자동 재시도/임의 취소, 증권사 매핑 추정, 현금 입출금 없는 자산 차액 수익률, 일별 거래가 없는 전략별 손익, 실주문 장애 복구, OS 무중단 실행 보장. 기존 세션 손실 한도는 재시작 때 기준 자산을 다시 잡는 **세션** 정책이다. 영속 일손실/입출금 조정 한도는 공식 현금흐름 계약을 확보한 뒤 별도 설계해야 하며 현재 구현한 것으로 표시하지 않는다.

## 보안·정책 근거

- [Android Storage Access Framework](https://developer.android.com/training/data-storage/shared/documents-files): 시스템 선택기에 의한 단일 파일 생성. 광범위 저장소 권한, 파일 URI 공유, 영구 URI 권한을 추가하지 않는다.
- [OWASP CSV Injection](https://community.owasp.org/attacks/CSV_Injection): 인용부호만으로 부족한 수식 주입 보호를 텍스트 경계에서 적용한다.

CSV와 ZIP 외부 복사본은 **암호화되지 않는다**. 사용자가 클라우드 제공자를 선택하면 그 제공자가 업로드할 수 있다. 앱 내부 Keystore 암호화/삭제는 외부 파일에 적용되지 않는다. UI에서 저장 전에 안내하며, API 키는 내보내기 자료 구조에 존재하지 않는다. 원시 시장 데이터 재배포 기능이 아니며 개인 계좌 관측 통계만 내보낸다. 실제 검증 결과는 [VERIFICATION.md](VERIFICATION.md).
