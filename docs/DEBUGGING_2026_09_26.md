# 요청 30 · 전체 디버깅

원문은 USER_REQUESTS.md의 요청 30이다. 이번 검토는 로컬 코드/회귀 중심이며 실제 주문을 보내지 않는다.

## 재현과 수정

| 문제 | 재현 | 수정 |
|---|---|---|
| 종료된 계좌의 WS 구독 복원 | A 인증 대기 → B connect 대기 → B close → A 완료 | lease 세대 검증 후 등록 |
| 취소 후 가능수량 응답이 주문 진행 | 취소 비협조 어댑터에 요청 → caller 취소 → 수량 반환 | 조회 후 ensureActive, 저널·전송 0건 |
| 저널 예약 중 취소 후 전송 | reserve 중 caller 취소 | 전송 직전 취소 검사, REJECTED·엔진 정지 |
| 새 분석 실패 후 이전 근거 유지 | 분석 성공 → 연도/보고서 변경 → 조회 실패 | 저장된 새 요청의 근거·후보 비움 |
| 내보내기 중 중복 콜백 | 문서 열기 지연 중 취소/중복 결과/launchFailed | writing 종료까지 busy 유지, 목적지 1회만 열기 |

JVM 신규 4개는 수정 전 실패를 실제 확인했다. 통계 저장 회귀는 Android 메모리 스트림/래치로 검증한다. 최종 수치와 실패 이력은 VERIFICATION.md에 기록한다.

## 검토 범위와 한계

계층 경계, 다중 계좌 실행/선택, 시세 REST/WS 전환, 주문 저널·가격/잔고 만료 검사, 그룹 체결 원장·파킹 소유권, 연구 갱신, 암호화 저장, 통계 집계·내보내기, 서비스/Manifest를 읽어 검토했다. 기존 조합 1,000개를 포함한 전체 회귀도 실행한다. 모든 실행 경로에 결함이 없다는 보증은 아니다.

실제 broker 주문/장시간 백그라운드/공식 휴장일·수정주가·뉴스·주문 대사 미완료는 COMPLETION.md와 RELEASE.md 그대로다. 이번에는 실제 키 API 시험을 수행하지 않는다. Android Keystore 검사는 기존 사용자 설치를 지우지 않는 disposable install에서만 수행한다.
