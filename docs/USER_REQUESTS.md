# 사용자 요청 원문 기록

이 파일은 사용자 요청 원문을 보존하는 누적 기록이다. 기존 원문은 요약으로 대체하거나 삭제하지 않는다. 새로운 요청은 구현·수정·검증을 시작하기 전에 먼저 추가한다. 구현 상태와 검증 결과는 별도 문서에 기록하며, 이 원문 기록 자체는 구현 완료 또는 검증 통과의 증거가 아니다.

## 2026-09-20 기록 — 현재 대화에서 전달된 요청 (전달 순서)

아래 날짜는 기록 날짜이며, 개별 메시지의 원래 발송 날짜를 뜻하지 않는다. 비밀 키 값은 포함하지 않는다.

### 12

```text
자동매매 전략은 물타기, 리밸런싱 2가지가 기본이야.
각 전략은 전략그룹으로 나눠서 여러개로 관리해줘.
각 전략그룹은 주식종목을 각각 가지고 있어서 동일 종목을 각 전략 및 전략그룹에 넣고 따로 관리(자동매매)가 가능해.

 전략은 추가 가능하게 구현해주고, 추천종목 매수 조건을 각 전략별 지정할 수 있게 해 줘.
1) 각 전략의 추천종목 매수 설정 -> 켜기/끄기, 각종 지표별 on/off, 조건값 설정. 추천지표조합 5가지 선택가능.
2) 각 전략별, 전략그룹별 정기매수 설정이 가능해.

UI는 직관적으로 구성해줘
```
